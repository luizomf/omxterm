# JetBrainsMono Nerd Font Mono

OMXTerm bundles the regular `JetBrainsMono Nerd Font Mono` webfont as its
default font and missing-glyph fallback. The operating system's monospace
fallback remains last in the Terminal Font Stack.

- Source: `ryanoasis/nerd-fonts` release `v3.4.0`, `JetBrainsMono.zip`
- Variant: `Mono`, keeping patched glyphs within one terminal cell
- Input reused from the repository-owned OMXTerm Web release asset
- Regular WOFF2 SHA-256:
  `50680a64466fbcc3eff68e00f84505f55681c86f8450c042416af5a8dbc1cce1`
- OFL SHA-256:
  `30f0c136e3c88e422d0791acd97238870f9054a9729bc34cf2ff0d4ed8cac4ad`
- License: SIL Open Font License 1.1; see `OFL.txt`

Only the regular weight is a v0 release input. OMXTerm does not download fonts
at runtime.
