# Use Electron for the desktop runtime

OMXTerm will use Electron because its TypeScript and web platform enable
fast iteration, unrestricted interface design, direct integration with local
Node.js capabilities, and selective reuse of experience from OMXTerm. The
project accepts Electron's larger memory, application-size, and startup costs
instead of competing with native terminals written in lower-level languages;
interactive terminal behavior must still remain responsive.
