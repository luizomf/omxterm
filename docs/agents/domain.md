# Domain docs

OMXTerm has one shared product context:

- [`CONTEXT.md`](../../CONTEXT.md) explains terminology.
- [`docs/spec.md`](../spec.md) defines current observable behavior.
- [`docs/adr/`](../adr/) records durable architectural decisions.

Read the relevant material for context and use shared terms where they clarify
the work. These documents describe the current product and decisions, not an
immutable authority over the maintainer's request. Update specifications,
contracts and ADRs when reconciling documentation with the product. Replace
obsolete guidance and explain the current rationale; Git retains the history.
Track supported code defects separately from documentation corrections, without
turning every discrepancy into a release blocker.
