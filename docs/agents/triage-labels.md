# Triage labels

Engineering skills use these exact GitHub labels for triage state:

| Skill role        | GitHub label      | Meaning                                   |
| ----------------- | ----------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`    | Awaiting initial evaluation               |
| `needs-info`      | `needs-info`      | More information needed from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent    |
| `ready-for-human` | `ready-for-human` | Ready for human implementation            |
| `wontfix`         | `wontfix`         | No action planned                         |

Preserve unrelated labels, such as issue type and priority, when changing triage
state.
