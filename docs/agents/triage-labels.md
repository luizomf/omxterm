# Triage labels

Maintainers use these GitHub labels for triage state:

| GitHub label      | Meaning                                   |
| ----------------- | ----------------------------------------- |
| `needs-triage`    | Awaiting initial evaluation               |
| `needs-info`      | More information needed from the reporter |
| `ready-for-agent` | Fully specified and ready for an agent    |
| `ready-for-human` | Ready for human implementation            |
| `wontfix`         | No action planned                         |

Preserve unrelated labels, such as issue type and priority, when changing triage
state.
