# AshyTerm feature parity matrix

Every feature found in the AshyTerm audit (`8d50567e`) with its OMXTerm port
status. Parity means equivalent **behavior** in OMXTerm's architecture, not the
same implementation technology.

**Status values**

- **verified**: implemented, covered by automated tests, and exercised in the
  real application on the platform named in the Evidence column.
- **implemented**: implemented and covered by automated tests; no real-app
  run yet on any platform.
- **partial**: some described behavior is still missing.
- **planned**: not started.
- **not ported**: deliberately excluded, with the reason given.

Windows and macOS columns describe the design. No feature is claimed for those
platforms until a native run is recorded in
[13-github-actions-matrix.md](13-github-actions-matrix.md).

**Abbreviations:** **L** Linux, **W** Windows, **M** macOS. **UT** unit tests;
the evidence files are under `test/unit/`. **RA** a real-application run on
Linux x86_64 under KDE Plasma (Wayland with XWayland), driven by `xdotool`.
