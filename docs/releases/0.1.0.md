# OMXTerm 0.1.0

> Pre-publication draft: `0.1.0` is the selected source version and `v0.1.0` is
> the intended later tag and target for a separately authorized GitHub Release.
> No `v0.1.0` tag, GitHub Release, public download, or accepted Release Artifact
> exists yet. Local DMGs are verification artifacts only.

## What is included

OMXTerm 0.1.0 is the first useful version of the open-source Personal Terminal.
It provides:

- the operating-system-configured shell as an interactive login shell in the
  user's home directory;
- independent native Terminal Windows with native new-window, close, copy,
  paste, select-all, zoom, fullscreen, always-on-top, and quit actions;
- compatibility with ordinary shells, user-started SSH, tmux, TUIs, REPLs,
  alternate-screen applications, Unicode, truecolor, bracketed paste, and
  in-memory scrollback;
- the bundled `omtheme` palette and JetBrainsMono Nerd Font Mono, with strict
  support for one configured external Terminal Theme and an installed font;
- strict version 1 JSON User Configuration, bounded local JSONL Operational
  Events, protected paste, restricted OSC 52 clipboard writes, sanitized
  titles, and validated visible HTTP/HTTPS links; and
- no application telemetry, analytics, crash reporting, update checks, or
  remote log delivery. Child processes keep their normal network access.

## Supported Platform

The only Supported Platform is Apple Silicon (`arm64`) on Otávio's current
macOS environment. Intel Macs and other operating systems are not supported by
this version.

## Known limitations

- OMXTerm has no tabs, splits, saved or reconnectable sessions, profiles, Shell
  Integration, automatic updates, AI assistance, or built-in remote terminal
  features. Closing a Terminal Window ends its Live Terminal Session; tmux
  remains the session manager.
- User Configuration and external Terminal Theme changes require a restart.
  There is no theme picker, theme catalog, or live reload.
- Distribution is Apple Silicon-only and intentionally unsigned and not
  notarized. The release process requires manual verification of one exact DMG
  before any publication can be authorized.

## Compatibility and migration

There is no previous published OMXTerm desktop version, so 0.1.0 introduces no
incompatible upgrade or migration. User Configuration and Terminal Theme files
use their independent version 1 schemas.

`OMXTerm-0.1.0-arm64.dmg.sha256` checksum are later accepted and publication is
separately authorized, the GitHub Release must include this required guidance:

> OMXTerm for Apple Silicon is intentionally not signed with an Apple Developer
> ID and is not notarized. macOS may warn that it cannot verify the developer or
> check the app for malicious software. Review the source, verify the published
> SHA-256, and proceed only if you trust this exact artifact. If you choose to
> open it, follow Apple's current [Open Anyway instructions](https://support.apple.com/102445)
> in System Settings -> Privacy & Security. Do not disable system-wide macOS
> security protections. This is the open-source build Otávio published and
> uses; it is not independently audited, approved by Apple, or guaranteed free
> of defects in all code and dependencies.

Artifact byte size and SHA-256 are deliberately omitted from this draft. They
belong first in the post-merge exact-artifact record and later in an
owner-authorized GitHub Release body.
