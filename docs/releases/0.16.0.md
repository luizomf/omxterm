## Changes

- Configure initial title-bar and tab-bar visibility with `window.showTitleBar`
  and `window.showTabBar`, both defaulting to `true`. The enabled tab strip
  appears only with two or more tabs.
- Toggle the current window's title area through View → Toggle Title Bar or
  remappable `Cmd+Shift+D` / `Ctrl+Shift+D`. Changes preserve the window,
  Terminal Surfaces and PTYs. Configuration initializes new windows; reload
  preserves existing windows' visibility choices while applying theme updates.
- macOS retains blended native traffic lights and a 30 px title inset. Linux
  and Windows use a themed 34 px custom title row in a frameless native window,
  with native window operations and guarded Busy Session closure.
- When the title is hidden, hovering within the top 150 logical pixels reveals
  a centered 90×14 logical-pixel native drag handle. Only the handle is a drag
  target; hover does not move layout or refit PTYs. Preview/fullscreen guards
  preserve the existing sessions.
- Accepted application Quit stops new session starts and waits for actual exits
  of all owned native PTYs, including sessions whose windows already closed.
  Busy confirmation still precedes shutdown.

No configuration or theme schema migration is required. Existing configuration
remains valid; there are no intentional incompatible changes or new runtime
dependencies. Blur and translucency are not included.

## Remaining risks and limitations

- macOS has an ad-hoc integrity seal, no Developer ID signature and no
  notarization. Linux and Windows are unsigned. No package has a verified
  publisher identity or an independent security-audit guarantee. Follow the
  per-file [Gatekeeper and SmartScreen guidance](../release.md#gatekeeper-and-provenance-note)
  only if you trust the exact checksum; do not disable system-wide protection.
- Linux requires X11/XWayland and retains its fixed `--no-sandbox` policy.
  Native Wayland and physical Linux dragging remain **UNVERIFIED**.
  `--appimage-extract-and-run` is the supported fallback when FUSE is unavailable.
- Exact-artifact physical gestures, macOS traffic-light/fullscreen interaction
  and first-download trust/privacy prompts remain **UNVERIFIED**. An ad-hoc
  identity change can require renewed macOS privacy approval. Earlier source
  fixtures, Windows native drag proof and reference dummies are not exhaustive
  manual verification of these exact packages.
- Historical Fedora ownership-registration failure #405 remains unexplained.
  Earlier Windows prompt timeouts/native crashes and the preparation occurrence
  with unknown preparer exit are retained separately. Current passing gates do
  not establish that every intermittent mechanism was eliminated.
- Packaged probes prove parsed positive cell dimensions and a nonempty
  `TERM_PROGRAM_VERSION`; they do not retain the literal live version string or
  numeric cell dimensions. Version metadata is separately verified as `0.16.0`.
  Probe group termination is not normal production Quit coverage.
