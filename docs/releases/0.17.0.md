## Changes since 0.16.0

- Optional background-only transparency and best-effort native blur (#412/#413).
  `window.blur` is a boolean (default `false`); `window.transparency` is a finite
  number from `0` to `1` (default `0`, opaque). Valid manual reload updates current
  and future windows without replacing windows, Terminal Surfaces or PTYs.
  Glyphs, cursor, selection and images are not faded; explicitly colored cell
  backgrounds remain opaque even when their RGB matches the theme background.
- macOS prefers direct native blur at fixed radius 20 with native white alpha
  0.001, through an optional main-only adapter; HUD vibrancy remains the fallback
  (#415). The renderer owns only the configured tint. No strength/material
  controls, renderer native capability or geometry workaround are added.
- Electron **43.4.1** corrects Linux native pointer resizing for transparent
  frameless windows (#416), retaining background composition and native controls.
  Windows retains Acrylic with its documented opaque fallback.
- Native scrollbar detection now honors a fine pointer on hybrid desktops that
  also report touch/coarse input, retaining touch-only exclusion (#418/#419).
  The same correction includes portable native-header test paths and production
  CSS constraints in the font-rendering fixture, not a font/core-WASM rewrite.

There are **no incompatible configuration changes or manual migrations**.
Configuration/theme schema version 1 remains valid. OMXTerm does not rewrite or
migrate existing files. See the [configuration guide](../configuration.md#background-transparency-and-blur),
[ADR 0029](../adr/0029-compose-background-effects-with-explicit-cell-identity.md)
and [ADR 0030](../adr/0030-prefer-direct-macos-background-blur.md).

## Known limits and provenance

- Native effects are best effort, not pixel-identical across platforms. GNOME
  blur is not claimed; Linux defaults to X11/XWayland, not native Wayland.
  The Linux resize correction reserves an internal **5-DIP input band**;
  fractional scaling, every edge/corner and all desktops are not qualified.
- Direct macOS blur uses undocumented APIs. Runtime evidence covers macOS 27
  ARM64 only; the macOS 12.0 deployment floor does not qualify older systems.
  Missing/failed effects use the documented fallback. **UNVERIFIED:** exact-final
  visible behind-window blur/physical desktop appearance and older macOS runtime
  compatibility; successful native return codes are not visible-blur proof.
- Windows plain transparency remains opaque without supported Acrylic; native
  success does not override OS policy. **UNVERIFIED:** physical GPU acceleration,
  visually observed final Acrylic and broader OS/GPU coverage.
- The original Windows paste timeout and isolated candidate `0xC0000005` remain
  **undiagnosed historical risks**, not fixed or benign. Subsequent candidate
  and final native passes do not establish elimination of every intermittent
  mechanism. No paste fix or long-path cause is claimed.
- Linux deliberately launches with **`--no-sandbox`** (ADR 0024). The complete
  package's **GLIBC 2.42** requirement excludes older library environments.
  If kernel FUSE is unavailable, use `--appimage-extract-and-run`; unavailable
  mounting is not a passing launch mode. No native-Wayland claim is made.
- No artifact has a verified publisher identity. macOS has a complete ad-hoc
  integrity seal, no Apple Developer ID signature or notarization; DMG is
  unsigned. Verify the published checksum and, only if you trust the artifact,
  follow Apple's [Open Anyway instructions](https://support.apple.com/102445).
  Do not disable system-wide protections. Ad-hoc identity changes may require
  renewed privacy approvals.
- Windows NSIS is unsigned. SmartScreen may report an unknown publisher; verify
  the checksum and use `More info -> Run anyway` only for the trusted exact file.
  Keep SmartScreen and Defender enabled. Linux artifacts are also unsigned.
- First-download trust/privacy prompts and exact-artifact physical gestures are
  **UNVERIFIED**. Automation and optional owner observations do not imply an
  independent security audit, platform-vendor approval or universal coverage.

A Mac checksum invocation initially used the wrong working directory; correcting
that directory verified unchanged bytes without repeating native gates. A Windows
bootstrap SSH receipt stalled, but successful native completion was recovered
without rerunning its payload. Neither is hidden or described as a product fix.
Earlier candidate failures and their distinct evidence remain preserved.
