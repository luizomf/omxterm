## Changes since 0.17.0

- The Linux desktop helper is now named **`linux_install.sh`**, with a matching
  checksum and embedded `--version`. It installs a verified local AppImage,
  selects FUSE or extraction, and uses the supported X11/XWayland backend.
  It downloads nothing and does not require sudo.
- Normal installation no longer asks desktop/GPU questions. Optional
  `install --compatibility` records software-graphics options only for graphical
  failures; normal reinstall removes that choice. Compatibility mode may be
  slower or less stable and still requires functioning WebGL2.
- Installation from an active Hyprland session can select a uniform monitor
  scale when XWayland zero-scaling is enabled. Missing tools/session data or
  mixed-scale monitors preserve normal Electron scaling. This is install-time
  selection, not live monitor tracking or a compositor configuration change.
- Newly created configuration files explicitly include `window.blur: false`
  and `window.transparency: 0`, making existing options easier to discover.
  Existing configurations remain untouched.
- Beginner onboarding and Hyprland/Omarchy documentation now explain the
  installation, interface scaling and compositor blur choices.

Configuration and theme schemas remain version 1, with **no manual migration**.
For download automation, replace the old version-bearing Linux helper filename
with `linux_install.sh` and its checksum **for this release only**. Old release
assets are unchanged. Always pair helper and AppImage from the same release.
