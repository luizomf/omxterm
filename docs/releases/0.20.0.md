## Changes since 0.19.0

- Local Image Preview recognizes an unquoted absolute image path containing spaces
  when it occupies the complete logical line. Preview capacity now supports static
  PNG/JPEG files up to 64 MiB encoded, 8192 pixels per side and 32 million pixels.
  Paths still address the machine running OMXTerm, including output from SSH;
  actual WebP and animated images remain unsupported.
- First-column bar cursors remain visible. Terminal session ownership is retired
  after exit, and native PTY resize failures are contained without closing sibling
  sessions. An unreadable Linux foreground process is not mistaken for an idle shell.
- Shortcut matching preserves AltGr as distinct from Alt/Control+Alt and reconciles
  intrinsic Shift accelerator identities. Windows literal PTY arguments preserve
  quoted whitespace.
- The Linux helper preserves originals after incomplete rollback, rejects unsupported
  destination entries, preserves literal desktop paths and bounds mount cleanup.
- Electron is updated to **43.7.7** for its preload-cache security correction.
  Native fixtures and release evidence reuse are improved without weakening package
  startup or installer verification.

Configuration, theme and snippet schemas remain version 1. **No manual migration
is required.** Existing user files are not rewritten.

### Windows ARM64 — PASS

Windows 11 ARM64 build 10.0.26200, native NTFS checkout, interactive desktop,
Node 24.15.0 ARM64 and Electron 43.7.7. Formatting, lint and typecheck passed.
**17 affected tests passed**; the unaffected **1410 passing tests / 98 skipped**

One native build/package and exact NSIS verification passed: ARM64 payload,
byte-identical installation, unpacked/installed Surface and PTY proof, privacy
canaries, uninstallation and owned-cache cleanup. Original guest state was restored.
Defender and SmartScreen remained enabled. Clean installation was exercised;
old-version replacement is UNVERIFIED for this exact installer.

The original run failed because a captured frame had no configured selection
pixels despite exact copied selection and two fixture animation-frame callbacks.
A controlled native scheduling experiment showed that this readiness predicate
can complete before the Surface paints: the held Surface callback yielded zero
selection pixels and correctly failed the readiness deadline; releasing that
callback yielded 3962 pixels without new input. The fixture now requires actual
captured readiness within three seconds, retaining the same palette/geometry
assertions and checking selection before and after captures. Permanently missing
pixels still fail. Synthetic first/last frames and state are retained on failure.

This is an evidenced **test-fixture correction**, not a product rendering fix or
reconstruction of the historical incident, whose original image was not retained.
That failure remains recorded; later unmodified diagnostic passes were not used
as acceptance. No macOS/Linux rebuild or full-suite retry was required.

## Limits and provenance

All packages are ARM64 only and have no verified publisher identity. macOS uses
an ad-hoc integrity seal, not Apple Developer ID signing or notarization. Windows
is unsigned. Linux retains the fixed `--no-sandbox` policy with context isolation.

macOS Gatekeeper may warn about an unverified developer. Review the source and
checksum; only if you trust this exact artifact, follow Apple's
[Open Anyway instructions](https://support.apple.com/102445) in
**System Settings → Privacy & Security**. Do not disable system-wide protections.

Windows Defender SmartScreen may warn about an unknown publisher. Review the
source and checksum; only if you trust this exact installer, use
**More info → Run anyway** for that file. Keep Defender and SmartScreen enabled.

UNVERIFIED: first-download security UI, physical keyboard/layout and picker
interaction, visible blur across compositors and older macOS versions, arbitrary
GPUs and operating-system versions. Historical intermittent hover observations
remain causally unresolved; non-recurrence is not proof of repair. Manual testing
is optional and no new manual coverage or independent security audit is claimed.

Development/build-time dependency audit warnings remain for `brace-expansion`,
`fast-uri` and `undici`. Native verification is not a clean security-audit claim.
