**Published and download-verified.**

Release tracking: [#561](https://github.com/luizomf/omxterm/issues/561).

## Changes since 0.20.0

- Fix terminal width reflow to preserve active rows, blank pinned rows and the
  live pending-wrap state.
- Suppress native scroll feedback caused by application-owned spacer clamps.
- Apply the existing Linux development sandbox policy before bootstrap.
- Refresh vulnerable transitive dependencies and improve native test readiness,
  fixture ownership and failure diagnostics.
- Clarify Windows Developer Mode and graphical execution prerequisites, plus
  additional Linux desktop compatibility and its limits.

This is a compatible patch release. Configuration, theme and snippet schemas
remain version 1. **No manual migration is required.** User files are not rewritten.

## Limits and provenance

ARM64 only. No artifact has a verified publisher identity. macOS has an ad-hoc
integrity seal, not Developer ID signing or notarization. Windows is unsigned.
Linux retains its fixed Chromium `--no-sandbox` exception and renderer isolation.

Gatekeeper may warn about an unverified developer. Review the source and checksum;
only if you trust this exact artifact, follow Apple's
[Open Anyway instructions](https://support.apple.com/102445) in
**System Settings → Privacy & Security**. Do not disable system-wide protections.
SmartScreen may warn about the unsigned Windows installer; if you trust it, use
**More info → Run anyway** for this file, without disabling Defender or SmartScreen.

**UNVERIFIED:** first-download security UI, physical keyboard/layout and picker
interaction, visible blur on older macOS/compositors, arbitrary GPUs and OS
versions. Manual testing is optional and no new exact-artifact manual coverage
or independent security audit is claimed. Earlier Mac installed-cache mtime
changes had no established writer; historical test PASS does not establish that
all production data was unchanged.

Cinnamon X11 and MATE retain known hover-test failures; experimental Cinnamon
Wayland has separate limitations. See the [Linux compatibility notes](../linux-installer.md).
These are not advertised as full-suite-qualified environments. Intermittent Mac
link-underline flicker and Fedora remote Alt-menu behavior remain unresolved
observations, not fixes promised by this release.

Fresh npm preparation reported **eight high-severity audit findings** in the
unchanged locked dependency set. This release does not claim a clean dependency
security audit; no unreviewed dependency upgrades were made during packaging.
