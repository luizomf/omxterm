# Historical release records

Each versioned file in this directory describes that release's behavior,
artifacts, checks, publication and limitations. It is not current product or
release guidance. Use the maintained [spec](../spec.md),
[usage guide](../usage.md) and [release procedure](../release.md) for today's
behavior and workflow; use the [current downloads](../../README.md#platforms-and-downloads)
for installation.

Records may be corrected for accuracy and clarity. Published tags and artifact
bytes remain unchanged. Preserve observed failures, PASS results, exact hashes,
source identities and unverified boundaries; a documentation correction is not
a rerun, repair or new qualification. Historical manual checklists and separate
owner-acceptance rounds do not impose requirements on current releases.

A historical unexplained failure is not automatically a current product defect
or release blocker. A later PASS also does not establish its cause or repair.
Assess current relevance and evidence reuse by the actual source, dependencies,
environment and affected boundary, rather than applying old process requirements.

See the [evidence inventory](../evidence/README.md) for raw-record provenance and
the release-evidence gaps reported in audit #566.
