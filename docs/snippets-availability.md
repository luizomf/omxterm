# Snippets availability

Snippets stores reusable commands or text so you can insert them from the
Snippets panel. It is an add-on for Linux (ARM64 and x64), Macs with Apple
silicon, and Windows on ARM. It is built in on Windows x64.

New installations try once to add it for you; it stays off until you open it.
Existing profiles don't get it automatically, and your snippets and your choice
to disable or remove it are kept.

The current Snippets (0.1.2) was checked on Linux ARM64 and macOS. It was not
checked on Windows ARM64 or Linux x64.

## Install or update

1. Open **Settings → Extensions → Browse official extensions** and choose
   **Install** or **Update** on the Snippets card.
2. Review the trust prompt before approving. The add-on runs with your
   account's permissions and is not sandboxed.
3. Return to a terminal tab, then choose **View → Toggle Snippets**.
